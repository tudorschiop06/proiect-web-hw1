# Proiect Web Design - Portofoliu Personal

**Scenariu ales:** Prezentarea proiectelor personale și a competențelor academice (Portofoliu).

### Checklist Cerințe Implementate:
- [x] Minim 4 pagini HTML corelate (Acasa, Proiecte, CV, Contact).
- [x] Utilizare CSS Extern pentru stilizare uniformă.
- [x] Validare W3C (HTML5 și CSS3) fără erori.
- [x] Element de accesibilitate: "Skip to main content".
- [x] Structură semantică (header, nav, main, section, footer).
- [x] Tabel stilizat pentru prezentarea abilităților.
- [x] Formular de contact cu diverse tipuri de input.

### Limitări cunoscute:
- Momentan site-ul nu folosește JavaScript pentru validarea dinamică a formularului.
