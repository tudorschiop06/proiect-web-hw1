# Proiect Web Design - Portofoliu Personal

**Scenariu ales:** Prezentarea proiectelor personale + CV (Portofoliu).

### Checklist Cerinte Implementate:
- Minim 4 pagini HTML (Acasa, Proiecte, CV, Contact).
- Utilizare CSS Extern pentru stilizare.
- Validare W3C (HTML5 și CSS3) fara erori.
- Element de accesibilitate: "Skip to main content".
- Structura semantică (header, nav, main, section, footer).
- Tabel stilizat pentru prezentarea abilităților.
- Formular de contact cu diverse tipuri de input.

### Limitari cunoscute:
- Momentan site-ul nu are parte de back end pentru ca formularul sa functioneze cum trebuie.
